# SkyCare 웹 데모

이 폴더는 **가상 항공편 데이터로 동작하는 정적 포트폴리오 데모**입니다.

- 실제 항공사 예약·환불 시스템과 연결되지 않습니다.
- 데모에 입력한 작업 내용은 브라우저의 localStorage에만 저장됩니다.
- 실제 API 서버는 저장소 루트의 `main.py`를 FastAPI로 실행해야 합니다.
- GitHub Pages 활성화: Settings → Pages → Deploy from a branch → main → /docs 
- 웹 데모: https://rlaqhfla0917-bit.github.io/skycare-disruption-api/
